🎚️ Piece Difficulty Audit

Independently re-assesses every library piece's level (0–5) against reputable sources (Henle level, ABRSM / RCM grade) using Claude + web search, and flags mismatches with the current rating.
Nothing changes until you tick corrections and Apply. Applying updates the level and regenerates that piece's "challenges" text so the prose matches the new level.
Scale: 0 Absolute Beginner · 1 Beginner · 2 Lower Intermediate · 3 Upper Intermediate · 4 Advanced · 5 Expert.
