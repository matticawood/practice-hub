# Practice Roadmap — Extra-tier objectives (draft map for review)

The dashboard now supports optional **Extra** objectives that chain off each baseline
goal: clear the baseline, its first Extra surfaces in its place (green + sink for the
done one), clear that and the next tier appears, and so on. Tiers colour up the ladder
(teal → violet → rose → gold). Hours still gate the level — Extras never advance you,
they keep a keen member moving while the hours accrue.

This doc proposes **what those Extras actually are**, level by level. Nothing here is
wired yet beyond the thin first pass; this is the content plan to agree before encoding.

---

## The model I'm proposing

Rather than invent separate Extras per level, define **master progressions** per skill
(an ordered list). Each level's **baseline** covers a prefix of that list; each level's
**Extras** are simply "the next items in the progression, one per tier." A keen member
at any level just keeps advancing along the same master list — so:

- **A First Steps member can go as far as they want** (their scale Extras run D, F, A, B♭, E♭ … well into Foundations territory).
- **An advanced Intermediate always has something** (their Extras reach up toward Confident/Advanced targets).
- **A less-advanced member always has something** (the next single, achievable step).

It also delivers the two things you asked for:
- **Prescriptive.** Broad goals like "all major scales" become named single steps.
- **Bridging.** Each Extra is literally a step toward the next level's expectation, and past it.

**How many tiers per level?** Scaled to the hours-gap to the next stage, because that's how
much time there is to fill:

| Level | Hours in-stage (to next) | Extra depth |
|---|---|---|
| First Steps | 50 | generous (keen beginners overstay a lot) |
| Beginner | 100 | generous |
| Foundations | 200 | deep |
| Intermediate | 350 | deep |
| Confident | 500 | very deep |
| Advanced | 800 | very deep |
| Performer | 1,500 | open-ended |
| Artist | top stage, open-ended | open-ended |

Because Extras follow master lists, "deep" mostly comes for free — the further down the
list a level's baseline sits, the fewer remain, so the **higher levels lean on rising
score targets, repertoire volume, and repertoire difficulty** to stay bottomless.

## Master progressions (the ordered lists — please correct the ORDER, it's your call)

### Major scales (hands together, two octaves)
`C · G · D · F · A · B♭ · E♭ · E · A♭ · B · D♭ · G♭`
(This matches your existing baselines: First Steps C,G → Beginner +D,F → Foundations +A,B♭,E♭ → then E, A♭, B, D♭, G♭ complete all 12.)

### Minor scales (natural + harmonic + melodic, hands together, two octaves)
`A · E · D · B · G · C · F♯ · C♯ · F · B♭ · G♯ · E♭`
(Matches Foundations A,E,D → Intermediate B,G,C → then the rest.)

### Arpeggios (follow the major-scale order)
`C · G · D · F · A · B♭ · E♭ · E · A♭ · B · D♭ · G♭` (major), then minor arpeggios in the same order.

### Note Recognition (score ladder + difficulty)
Target ladder: `10 · 14 · 18 · 22 · 26 · 30 · 34 · 38 · 40 · 44 · 48`
Difficulty ladder (applied as you climb): in a named key → across the level's keys → **mixed clef** → **with accidentals** → sight-read speed.

### Chord Recognition (score + difficulty)
Difficulty ladder: triads **in a key** → triads **free (no key)** → **triads + inversions** → **sevenths** → **sevenths + inversions** → extensions. Score targets rise 8 → 12 within each stage.

### Ear Training (score + set)
Set ladder: major vs minor → **triads** (maj/min/dim/aug) → **sevenths** → **extensions/progressions**. Scores rise 10 → 16 within each set.

### Theory (course levels 1–5)
Baseline completes level N; Extra = **begin level N+1**, then **complete level N+1** (a 2-tier bridge into the next theory level while the hours build).

### Sight-reading (minutes, accumulating — already a goal type)
Extras raise the **difficulty band** of the read-once material (a grade below current playing standard, then at standard) and add further minute milestones.

### Improvisation (hours, accumulating)
Extras add hours **and** get more prescriptive: triads + melody → add 7ths → over a ii–V–I → in a chosen key/mode → trading 4s over a backing.

### Repertoire (pieces, by difficulty tier 0–5: Absolute Beginner … Expert)
Extras add **count** at the current tier, then **reach up one tier** for a stretch piece. Matt's Picks already surfaces the next specific piece.

## Per-level breakdown

Notation: each line is `skill — baseline → Extra tier 1 → tier 2 → …`. Extras are optional and revealed one at a time.

### 1 · First Steps  (0–50 h · before Grade 1)
- **Scales** — baseline **C, G** → **D** → **F** → **A** → **B♭** → **E♭** (a keen beginner can climb the whole major order)
- **Note Recognition** — baseline **10 (C, G)** → **12** → **14** → **16** → **18 (adds D, F)**
- **Repertoire** — baseline **1 Absolute Beginner piece** → **2nd** → **3rd** → **a first Beginner-tier piece**
- **Theory** — baseline **begin Level 1** → **complete Level 1**
- **Sight-reading** — baseline **500 min** → **750** → **1,000 min**
- *(Arpeggios and minors don't start until Beginner/Foundations — no Extras here.)*

### 2 · Beginner  (50–150 h · around Grade 1–2)
- **Scales** — baseline **C, G, D, F** → **A** → **B♭** → **E♭** → **E** → **A♭**
- **Arpeggios** — baseline **C, G, D, F** → **A** → **B♭** → **E♭**
- **Note Recognition** — baseline **18 (CGDF)** → **22** → **26** → **30** → **34 (mixed clef)**
- **Chord Recognition** — baseline **10 (CGDF triads in key)** → **12** → **triads free, 10**
- **Ear Training** — baseline **12 (maj/min, CGDF)** → **14** → **16** → **triads, 12**
- **Improv** — baseline **3 h** → **+2 h with 7ths** → **+2 h over ii–V–I**
- **Theory** — baseline **complete Level 1** → **begin Level 2**
- **Repertoire** — baseline **4 Beginner pieces** → **5th** → **6th** → **a Lower Intermediate stretch piece**
- **Sight-reading** — baseline **1,000 min** → **1,500** → **2,000 min**

### 3 · Foundations  (150–350 h · around Grade 3–4)
- **Scales** — baseline **A, B♭, E♭** → **E** → **A♭** → **B** → **D♭** → **G♭** (completes all 12 major)
- **Arpeggios** — baseline **A, B♭, E♭** → **E** → **A♭** → **B** → **D♭** → **G♭**
- **Minor scales** — baseline **A, E, D (nat/harm/mel)** → **B** → **G** → **C**
- **Note Recognition** — baseline **18 (A, B♭, E♭)** → **24** → **30** → **34 (mixed clef + accidentals)**
- **Chord Recognition** — baseline **10 (triads free)** → **triads + inversions, 9** → **12**
- **Ear Training** — baseline **16 (triads)** → **sevenths, 10** → **12**
- **Theory** — baseline **complete Level 2** → **begin Level 3**
- **Repertoire** — baseline **1–2 Lower Intermediate** → **3rd** → **4th** → **an Upper Intermediate stretch piece**
- **Sight-reading** — baseline **2,000 min** → **3,000** → **3,500 min (at, not below, standard)**

### 4 · Intermediate  (350–700 h · around Grade 5)
> **Recommendation:** make the baseline prescriptive here. Baseline "all major scales" → baseline **the 12 named major scales you should now hold** (they're all covered by Foundations Extras), and use Extras to push into **speed/quality and 3rd/6th apart**, not just coverage.
- **Scales** — baseline **all 12 major secure, HT 2 oct** → **at ♩=88 in even quavers** → **in sixteenths** → **a third apart / a sixth apart** → **contrary motion from C**
- **Arpeggios** — baseline **all major** → **all minor arpeggios (same key order)** → **dominant 7ths in common keys**
- **Minor scales** — baseline **B, G, C** → **F♯** → **C♯** → **F** → **B♭** → **G♯** → **E♭** (completes all 12 minor)
- **Note Recognition** — baseline **34** → **36** → **38** → **40**
- **Chord Recognition** — baseline **9 (triads + inversions)** → **sevenths, 7** → **10**
- **Ear Training** — baseline **12 (sevenths)** → **14** → **progressions, 10**
- **Improv** — baseline **+5 h** → **+3 h in a minor key** → **+3 h trading 4s over a backing**
- **Theory** — baseline **(carry Level 2)** → **complete Level 3** → **begin Level 4**
- **Repertoire** — baseline **5 intermediate pieces** → **6th** → **7th** → **an Upper Intermediate stretch** → **an Advanced stretch**
- **Sight-reading** — baseline **3,500 min** → **5,000** → **6,000 min**

### 5 · Confident  (700–1,200 h · around Grade 6–7)
- **Scales** — baseline **all major + minor, every key, 16ths @ 88** → **@ 100** → **@ 112** → **in thirds** → **in sixths** → **chromatic + whole-tone**
- **Arpeggios** — baseline **all major + minor** → **dominant 7ths, all keys** → **diminished 7ths, all keys**
- **Note Recognition** — baseline **40** → **44** → **48** → **sight-read speed drill**
- **Chord Recognition** — baseline **7 (sevenths free)** → **10** → **sevenths + inversions, 8**
- **Ear Training** — baseline **14 (sevenths)** → **16** → **short progressions, 10** → **12**
- **Theory** — baseline **(carry)** → **complete Level 4** → **begin Level 5**
- **Repertoire** — baseline **6 Upper Intermediate** → **7th** → **8th** → **an Advanced stretch** → **a second Advanced piece**
- **Sight-reading** — baseline **5,000 min** → **6,500** → **8,000 min**

### 6 · Advanced  (1,200–2,000 h · around Grade 8)
> Baseline is thin (all scales/arps fluent + sight-read + 6 Advanced pieces). This is where **repertoire volume and difficulty** carry the load — the hours gap is 800.
- **Scales** — baseline **all scales fluent, every key** → **at concert tempo** → **double thirds in easy keys** → **octaves, hands together** → **in tenths**
- **Arpeggios** — baseline **all fluent** → **dominant + diminished 7ths at tempo** → **arpeggios a tenth apart**
- **Ear/theory** — baseline **complete Theory Level 5** → **analyse a piece you're learning (harmonic outline)**
- **Repertoire** — baseline **6 Advanced pieces** → **7th** → **8th** → **a first Expert stretch piece** → **a second Expert piece** → **an Advanced work from memory**
- **Sight-reading** — baseline **8,000 min** → **10,000** → **12,000** → **15,000 min (accompaniment reading)**
- **Improv/performance** — **improvise a cadenza-style passage in a piece's style** → **perform one Advanced piece to standard**

### 7 · Performer  (2,000–3,500 h · diploma standard)
> Open-ended; the hours gap is 1,500. Lean on **programme-building, memory, and Expert repertoire**.
- **Repertoire** — baseline **balanced Advanced programme + 5 advanced-to-expert pieces** → **+1 Expert piece** → **+2** → **+3** → **a full contrasting recital set**
- **Performance** — **perform your programme from memory** → **perform to an audience / record it** → **a themed programme (one composer or era)**
- **Sight-reading** — baseline **15,000 min** → **accompany another instrument/singer** → **read an orchestral reduction**
- **Musicianship** — **transpose a piece at sight** → **harmonise a given melody** → **improvise in a named style**

### 8 · Artist  (3,500 h+ · top stage, open-ended)
> No next level — Extras are purely "keep growing," bottomless by design.
- **Repertoire** — baseline **full Expert programme + an Expert work made your own** → **a second Expert work** → **a large-scale work (sonata/suite)** → **commission or arrange a piece**
- **Performance** — **give a full recital** → **a themed recital** → **teach/coach the piece to someone else**
- **Musicianship** — **improvise a complete piece** → **compose a short original** → **arrange for another instrument**
