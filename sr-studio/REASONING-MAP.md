# The Reasoning Map — every element of a piece, and whether the generator has a REASON for it

**The standard (Matthew):** every element on the page must exist for a compositional REASON — motif, variety, tension/release, phrase shape, cadence, character, function — never because it was "one of N options" chosen at random. This document is the exhaustive list of every element that can make up a piece of music. Each gets a status once audited: **REASONED** (chosen for a stated musical reason) / **PARTIAL** (constrained but not fully justified) / **ARBITRARY** (random-within-limits or generate-and-reject) / **ABSENT** (not built). The goal: no ARBITRARY, no unjustified PARTIAL.

Status column filled from the six-part code audit in progress.

## 1. PITCH & MELODY
- Individual pitch choice (which note, and why THIS note)
- Chord-tone vs non-chord-tone role of each note
- Non-chord tones, each prepared & resolved: passing, upper/lower neighbour, appoggiatura, escape tone (échappée), anticipation, suspension, retardation, cambiata/changing-tones, pedal tone
- Melodic interval size (unison/step/leap)
- Leap treatment — preparation into, recovery/step-back out of
- Melodic contour / shape (arch, rise, fall, wave, terraced, valley…)
- Range / ambitus of the line
- Melodic climax / apex — the single high point and where it falls
- Register / octave placement of the melody
- Repeated notes (kept only if motivic or a device, else varied)
- Chromaticism / accidentals — chromatic passing/neighbour, applied-chord tones, borrowed, raised leading tone in minor
- Cadential melodic formula — how the line lands at each cadence
- Leading-tone resolution / tendency-tone treatment

## 2. MOTIF & MOTIVIC DEVELOPMENT
- The core motif / basic idea (pitch + rhythm cell)
- Repetition (exact)
- Transposition / real & tonal sequence
- Inversion
- Retrograde
- Augmentation / diminution (rhythmic)
- Fragmentation / truncation
- Extension / interpolation / liquidation
- Ornamented or embellished variation
- Motivic consistency across the piece (recurrence has a reason)

## 3. RHYTHM & DURATION
- Note values that appear (and why each)
- The rhythmic cell / pattern (rhythmic motif)
- Held / long notes — justified as breath, cadence arrival, deliberate contrast
- Repeated rhythmic pattern (motivic vs monotonous)
- Rests — placement & function (breath, articulation, syncopation, texture, one-hand-drops-out)
- Ties (and syncopation-by-tie)
- Dotted rhythms
- Syncopation
- Anacrusis / upbeat / pickup
- Tuplets (triplets etc.)
- Hemiola / cross-rhythm
- Rhythmic density / activity level (per bar, per section)
- Agogic emphasis (length as accent)
- Beaming / notational grouping reflecting the metre

## 4. HARMONY
- Chord vocabulary available (per grade)
- Chord choice / function (tonic / predominant / dominant)
- Chord quality (maj/min/dim/aug, 7ths & extensions at grade)
- Chord inversion & the bass note under it
- Harmonic rhythm — HOW OFTEN the chord changes, and why (faster into cadence, slower at rest)
- Chord voicing & spacing (open/close, which doublings)
- Voice leading between chords (common tones, least motion, no parallels)
- Functional progression / grammar (no retrogression, D resolves)
- Bass line shape / walking bass / non-chord bass motion
- Pedal point (tonic / dominant pedal, with reason)
- Harmonic sequence
- Tonicization / secondary (applied) dominants
- Modulation (key change) and its preparation
- Suspensions & tension chords
- Modal mixture / borrowed chords, chromatic chords (Neapolitan, aug-6th) at higher grades
- Doubling rules (double the root, avoid doubling the leading tone…)

## 5. KEY & TONALITY
- Key signature / key choice
- Mode (major / minor; natural, harmonic, melodic minor usage)
- Establishment of the tonic (opening) and confirmation (close)
- Modulation destinations & relationships (relative, dominant, parallel)

## 6. METRE & TIME
- Time-signature choice (and why it fits the character)
- Simple vs compound; duple / triple / quadruple
- Metric accent — strong/weak beat hierarchy driving placement
- Beat / division structure
- Metre change (higher grades)

## 7. FORM & STRUCTURE
- Phrase length & internal structure
- Phrase relationships — antecedent/consequent, parallel/contrasting period
- Sentence structure (presentation / continuation / cadential)
- Motif → phrase → period hierarchy
- Repetition / restatement / varied restatement
- Number of bars / total length
- Sectional form (binary, ternary…) for longer pieces
- Balance, proportion, symmetry of phrases
- Structural climax placement (often the golden section)
- Opening (establishing) & closing (cadential) gestures
- Phrase elision / overlap

## 8. TEXTURE & PART-WRITING
- Texture type (monophonic / homophonic melody+accompaniment / contrapuntal / homorhythmic)
- Accompaniment pattern (Alberti, broken chord, block, oom-pah, arpeggiated, waltz, walking bass, sustained)
- Texture consistency vs purposeful change (identity vs bar-to-bar randomness)
- Number of voices / density
- Two-hand relationship — melody+accompaniment, doubling (8ve/3rd/6th), complementary rhythm, dialogue/call-response, imitation, melody-in-LH (swap)
- Inner voices / counterpoint (higher grades)
- Foreground/background balance (tune sings over accompaniment)
- Register spacing between hands / voices

## 9. DYNAMICS
- Base dynamic level (from character)
- Dynamic level changes — terraced vs gradual, each justified by intensity/phrase/structure
- Hairpins (cresc/dim) following the intensity curve (melody + harmonic tension)
- Subito / echo dynamics (structural reason)
- sf / fp / accent-level marks
- Dynamic climax aligning with the structural climax
- Grade-appropriate dynamic range

## 10. ARTICULATION
- Legato / slurs & phrase marks (a real phrase or sigh)
- Staccato / staccatissimo (on playable, appropriate notes)
- Tenuto
- Accent (>) / marcato
- Portato
- Consistency of articulation on a recurring figure

## 11. TEMPO & PERFORMANCE DIRECTIONS
- Tempo mark / BPM
- Character / mood direction (Italian + English), matched to the actual fabric
- Style indication (alla marcia, scherzando, cantabile…)
- Expression words (espressivo, dolce…)
- Tempo change (rit., accel., a tempo — higher grades)
- Fermata / pause (structural reason)

## 12. ORNAMENTATION (grade-dependent)
- Grace note / acciaccatura / appoggiatura
- Trill, turn, mordent
- Spread / rolled chords

## 13. TECHNIQUE & NOTATION LAYER
- Fingering (playable, position-appropriate)
- Hand position & shifts (five-finger at G2; shifts later)
- Pedalling — sustain, una corda (higher grades)
- Clef changes (higher grades)
- Enharmonic spelling (raised leading tone spelt sharp, etc.)
- Beaming / stem / notation correctness

## 14. THE UNIFYING LAYER (coherence — the meta-reason)
- Character / affect — the ONE governing idea every other element serves
- Style / genre / idiom (waltz, march, lullaby, chorale, dance…)
- Coherence — every element DERIVED from the character, not chosen independently and filtered
- Tension / release architecture (the intensity arc the whole piece traces)
- Gesture / rhetoric / directionality (the sense the piece is going somewhere)
- Stylistic consistency (nothing that contradicts the idiom)

## 15. ELEMENTS THE FIRST LIST MISSED (added by the audit)
- Modulation / tonal plan (key change within a piece) — absent, ~G5+
- Hemiola / metric-grouping dissonance (3s against 2s) — absent
- Larger form & structural repeats (binary/ternary, repeat barlines, 1st/2nd time) — absent
- Hypermeter / phrase-length asymmetry & elision (3+5, overlapping ends) — absent (phrases forced symmetric)
- Countermelody / voice independence / imitation (horizontal two-voice relationship) — absent (roadmap VOICES model)
- Tempo modification within a piece (rit./accel./a tempo) — absent, ~G5+

# SYNTHESIS — verdict per element (six-part code audit, complete)

**REASONED (meets the standard — chosen for a stated musical reason):** harmonic progression & chord choice · cadence PLACEMENT + approach · phrase/period structure · key choice · secondary-dominant mechanism · REST placement · passing/neighbour/suspension NCTs · leap RECOVERY · register & hand separation · chord voicing/spacing/inversions · voice leading (parallels/crossing/dropped-3rd guarded) · inner counter-line + walking bass · DYNAMIC intensity curve · hairpin placement · staccato · accent · tenuto · tempo-mark→fabric coupling · anacrusis shape · syncopation (gated) · ties/suspensions · bar-count · fingering · rhythmic-motif DEPLOYMENT · **the character→whole-fabric COHERENCE architecture (the engine's real strength)**.

**NOT FULLY REASONED — the gaps, grouped by root cause:**

**A. Dead per-character intent (quick wins).** `character.dyn / hair / ferm` are authored in the table but READ ZERO TIMES — a Maestoso and a scherzo open and pause identically. Root of several dynamics/fermata gaps.

**B. The recurring root fault — per-instance magnitude/placement drawn i.i.d., NOT coupled to phrase-function.** The vocabulary/constraints are reasoned but the actual pick is a die uncoupled from where the phrase is (drive / repose / apex / cadence) and from motif membership:
- note-length DENSITY (which duration in which bar) — not pushed toward drive, pulled at repose
- HELD-note placement — random MACRO draw, not bound to repose/apex/contrast
- REPEATED notes — kept/broken by dice+count, not "is it the motif" (breaks real tattoos, keeps meaningless repeats) ← Matthew's explicit example
- TEXTURE member — random within the correct character bucket; swap/compound branches ignore character
- melodic APEX / contour shape — random shape, apex not aligned to the harmonic climax (peakBar)

**C. Reasoned-selection leaks (encode the entailment/deny-list).**
- SLUR placement — generic bar-count templates, not the actual phrase/gesture boundaries
- DYNAMIC SCHEME choice — profile lottery, not entailed by what the piece has (restate→echo, energy jump→subito…)
- CADENCE TYPE — perfect-vs-plagal coin-flip, not character-driven; INTERRUPTED specified but unbuilt; `gp.harmony.cadences` unread
- FERMATA caesura — ignores `midType` (can pause a `continuous` seam)
- HARMONIC RHYTHM — rate not derived from tempo/metre; acceleration is a single pre-cadence spike; mid-bar split hard-locked to grade===4

**D. Absent capabilities (real builds; mostly already on BUILD-STATUS roadmap).**
- MELODIC SEQUENCE — absent (biggest missing form device)
- PITCH-MOTIF DEVELOPMENT (transposition/inversion/fragmentation) — absent; only verbatim restate + figure-type bias
- APPOGGIATURA / escape / anticipation NCTs — not generated (chord-tone-on-beat skeleton fakes their absence)
- LEAP decision stochastic; 5th cap fakes leap-recovery
- TWO-HAND RELATIONSHIP — homophony hard-wired (no doubling/dialogue/countermelody/imitation)
- MODULATION, HEMIOLA, structural repeats, hypermeter, tempo-change — absent (higher-grade)

# FIX ORDER
1. **Wire the dead character fields** (dyn/hair/ferm) + fermata `midType` gate + dynamic-scheme entailment + slur-from-phrase + cadence-type-by-character (+ interrupted) + texture-member-by-tempo/motion. Contained fixes to already-reasoned subsystems.
2. **Build ONE per-bar PHRASE-FUNCTION / tension profile** (drive / repose / apex / cadence, from contour+harmony+position) and couple note-length density, held-note placement, repeated-note keep/break, and contour apex to it. This is the single reasoning layer that fault B is missing — fixes many gaps at once.
3. **Harmonic rhythm** from tempo/metre + acceleration curve, ungated from grade 4.
4. **Absent devices**: melodic sequence + pitch-motif development; appoggiatura; then two-hand relationships (bigger; some G5+).

# FUTURE WORK — grade 5+ and beyond (parked, deliberately not built for grades 2-4)

These are real capabilities the reasoning audit identified as ABSENT, but which correctly belong to grades the generator does not yet target. They are the roadmap once grades 5-8 are in scope.

## The G5+ VOICES / part-writing model (the big one)
Higher grades move from homophony to genuine PART-WRITING: multiple independent voices, inner melodies, countermelody, and counterpoint up to imitation. Syllabus anchors: 4-part chords (2 per hand) at G5, 3-part in either hand at G8. Architecture: generalise "melody + accompaniment" into N voice-led voices where voice-count and independence are GRADE PARAMETERS (2 / homophonic low; 4 / contrapuntal high). Subsumes the two-hand-relationship work below.

## Further two-hand RELATIONSHIP types (beyond the doubling now built)
Doubling (parallel tenths) is done. Still to build, each chosen per piece and composed with the second hand aware of the first: DIALOGUE / call-response (hands alternate the line), COUNTERMELODY (a second independent tune under/over the melody), IMITATION / canon (one hand answers the other's figure). All register- and voice-leading-aware.

## Higher-grade syllabus features (grade-parameter unlocks)
- MODULATION / tonal plan (key change within a piece) — ~G5+
- Generalised secondary dominants V/x (V/ii, V/vi, V/IV...) beyond the current V/V-only
- HEMIOLA / metric-grouping dissonance (3s against 2s)
- Larger FORM: binary / ternary / rounded binary, repeat barlines, 1st/2nd-time bars; hypermetric / phrase-length asymmetry (3+5, elision)
- TEMPO modification within a piece (rit. / accel. / a tempo) — ~G5-7
- ORNAMENTS (grace / trill / turn / mordent) — G8; PEDALLING — G6; 8va — G7; CLEF changes — G6; SPREAD chords — G8
- Wider leap ceiling with built leap-recovery (currently the 5th cap fakes it) — ~G7

## Minor refinements at the current grades (nice-to-have, not gaps)
- Some heuristic thresholds/chances are reasoned in DIRECTION but not derived in exact degree
- Book-level key/metre COVERAGE stratification (currently i.i.d. random per piece)
